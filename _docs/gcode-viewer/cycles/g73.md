# G73 pattern repeating cycle

Status: PARTLY VERIFIED against helmancnc and gcodetutor (word format only) / UNVERIFIED: exact
per-pass offset formula, whether the tool returns to A between passes, and the one-line
I/K/D form — Haas's own G73 page returned HTTP 403 (tried once per instructions, not retried);
no Fanuc manual PDF was reachable from the tutorial pages. Re-checked in Task 12b (cnccookbook.com,
gcodetutor.com again, cnccode.com again): still unverified, see the sweep section below.

Fanuc two-line form:
    G73 U(Δi) W(Δk) R(d)
    G73 P(ns) Q(nf) U(Δu) W(Δw) F

- Δi: total relief in X (radius value, signed); Δk: total relief in Z (signed).
- d: number of divisions (passes), a count.
- Δu: X finishing allowance (diameter); Δw: Z finishing allowance.
- One-line form (older Fanuc / Haas): G73 P Q I(Δi) K(Δk) U W D(d) F.

Motion: pass k = 1..d follows the P…Q profile shifted by
    x: Δu/2 + Δi·(d−k)/(d−1)      z: Δw + Δk·(d−k)/(d−1)    (d = 1: allowance only)
Each pass: rapid from A to the shifted profile start → cut along the shifted profile → rapid back to A.

Open question — does the tool return to A between passes, or step directly to the next pass
start? NOT settled by any reachable source; kept as the brief's assumption (return to A after
every pass) because no source contradicts it.

  `https://www.haascnc.com/service/codes-settings.type=gcode.machine=lathe.value=G73.html`
  — HTTP 403, as flagged in sources.md for this session. Not retried.
- helmancnc, "CNC Fanuc G73 Pattern Repeating Cycle" (secondary, tutorial site; reached by
  following the G73 link from the G70/G71 article):
  `https://www.helmancnc.com/cnc-fanuc-g73-pattern-repeating-cycle/`
  — Confirms the two-block word format: first block `G73 U W R` (U = relief distance/direction in
  X, radius value; W = relief distance/direction in Z; R = number of divisions the contour is
  repeated), second block `G73 P Q U W` (P = contour start block, Q = contour end block, U/W =
  finishing allowance in X/Z). Matches the brief's Δi/Δk/d/Δu/Δw reading. Does not state the
  offset formula, pass count beyond "R3" in its example, or whether the tool returns to A.
- gcodetutor, "G73 Pattern Repeating Cycle" (secondary, tutorial site; reached by following the
  G73 sidebar link from the G71 article):
  `https://gcodetutor.com/cnc-machine-training/g73-pattern-repeating-cycle.html`
  — Same two-block format: `G73 U(1) W(1) R;` / `G73 P Q U(2) W(2) F;`, with U(1)/W(1) as
  "depth of cut" in X/Z, R as "amount of roughing passes", U(2)/W(2) as finishing allowance.
  Explicitly states this page does not reference I, K, or D (i.e. no one-line form shown here).
  No offset formula or return-to-A statement.
- cnccode.com, combined G71/G72/G73/G70 guide (secondary, tutorial site, listed in sources.md):
  `https://cnccode.com/2025/10/10/cnc-canned-turning-cycles-g71-g72-g73-g70-complete-roughing-finishing-guide/`
  — Describes U as "depth per pass" and R as "retract amount between passes", which conflicts
  with helmancnc/gcodetutor's "total relief" / "number of divisions" reading and looks like a
  generic/lower-quality summary rather than a careful transcription of the Fanuc manual. Not
  treated as authoritative: it disagrees with two independent, more specific tutorial sources and
  gives no worked example, so the two-source reading is kept and this page's text is not used to
  change the note.
- No Fanuc manual PDF was found linked from any of the above pages.

None of the reachable sources contradict the brief's offset formula, pass order, one-line word
meanings, or the return-to-A assumption, so `g73.js`, the `index.js` handler, and the test are
