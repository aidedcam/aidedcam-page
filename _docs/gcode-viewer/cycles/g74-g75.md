# G74 / G75 peck cycles

Status: VERIFIED against helmancnc (G74 peck drilling, G75 grooving cycle, G75 one-line format,
G75 worked program example) and gcodetutor (G75 groove cycle). Haas's own G74/G75 pages returned
HTTP 403 (tried once each per instructions, not retried); no Fanuc manual PDF was reachable from
any of the tutorial pages.

Fanuc two-line forms:
    G74 R(e)
    G74 X(U) Z(W) P(Δi) Q(Δk) R(Δd) F      Δi = X shift between grooves (µm, radius), Δk = Z peck (µm)
    G75 R(e)
    G75 X(U) Z(W) P(Δi) Q(Δk) R(Δd) F      Δi = X peck (µm, radius), Δk = Z shift between grooves (µm)

- e = retract after each peck (chip break); Δd = relief at the bottom (not drawn in v1).
- P/Q are integers in µm; a decimal point there is a programming error (check pq-decimal).

Motion per column: feed one peck, rapid back by e, feed the next peck … the last feed reaches the end
exactly, then rapid back to the start of the peck axis. Next column: rapid shift. After the last
column: rapid back to A.

Hand-worked examples (become the tests):
- G74 drilling from (r0, z2): R1 / Z-20 Q5000 → Z targets -3, -2, -8, -7, -13, -12, -18, -17, -20, 2 (10 moves).
- G75 grooving from (r26, z-10): R0.5 / X40 Z-14 P2000 Q3000 → columns z -10, -13, -14; column 1 X
  targets 24, 24.5, 22, 22.5, 20, 26; 21 moves in total, ending at A.

## Sources checked

- helmancnc, "Simple CNC Lathe Drilling with Fanuc G74 Peck Drilling Cycle" (secondary, tutorial
  site; reached by following the G74 link from the helmancnc G-code list):
  `https://www.helmancnc.com/simple-cnc-lathe-drilling-with-fanuc-g74-peck-drilling-cycle/`
  — Two-line form `G74 R1` / `G74 Z-60 Q30000 F0.1`. Confirms R = retract distance after each peck
  ("the amount (1mm) the drill will get back after it drills 30mm every time") and Q = peck depth
  in Z (µm-scale integer, 30000 = 30mm). Matches the brief's e/Δk reading for G74. Does not define
  X/U/W/I/K/P/D or state the final-peck behaviour.
- helmancnc, "Drilling Brass 40mm Deep Using G74 Drilling Cycle" (secondary, tutorial site; linked
  from the same G74 article):
  `https://www.helmancnc.com/drilling-brass-40mm-deep-using-g74-drilling-cycle-cnc-turning-program/`
  — A second worked program (`G74 R2.` / `G74 Z-40. Q5000 F0.1`) using the same two-line form;
  gives no extra detail on the retract/final-peck mechanics beyond the first article.
- helmancnc, "CNC Fanuc G75 Grooving Cycle" (secondary, tutorial site; reached from the helmancnc
  G-code list):
  `https://www.helmancnc.com/cnc-fanuc-g75-grooving-cycle/`
  — Two-block form `G75 R` / `G75 X Z P Q R`, with P = "peck increment in x-axis (depth of each
  cut in x-axis)" and Q = "stepping in z-axis (axial advancement between cuts)". States G75 "works
  very similar to G74 peck drilling cycle." Matches the brief's P=Δi(X peck)/Q=Δk(Z step) reading
  for G75, and by the stated G74/G75 symmetry supports P=Δi(X step)/Q=Δk(Z peck) for G74.
- helmancnc, "Fanuc G75 Grooving Cycle One-Line Format" (secondary, tutorial site; linked from the
  G75 article):
  `https://www.helmancnc.com/fanuc-g75-grooving-cycle-one-line-format/`
  — One-line form `G75 X Z I K D`, with I = "depth of each cut" (X peck), K = "stepping in z-axis"
  (Z step), D = "relief amount at the end of cut". Confirms the brief's I/K reading for the
  one-line form and the existence of a bottom-relief word (D, not yet drawn in v1).
- helmancnc, "Fanuc G75 Grooving Cycle CNC Program Example" (secondary, tutorial site; linked from
  the one-line-format article):
  `https://www.helmancnc.com/fanuc-g75-grooving-cycle-cnc-program-example/`
  — Full worked program including `G75 R1` / `G75 X90 Z-60 P2000 Q3000 R0 F0.1`, explained as:
  "Every time the grooving tool will take 2mm (P2000) cut in x-axis, and it will retract 1mm
  (Pecking, First R1)... After a groove in x-axis is complete it will start the next groove by
  moving the grooving tool by 3mm (Q3000) in z-axis." This directly confirms: P is the X peck
  depth (2mm from P2000, i.e. µm/1000), the first R is a **partial** per-peck retract (1mm, not a
  full return to the column start), and Q is the Z step between columns (3mm from Q3000) — exactly
  the brief's motion model (peck, retract by e, peck again; step to next column in Q/step-axis).
- gcodetutor, "G75 Groove Cycle" (secondary, tutorial site; reached by following the G75 link from
  the gcodetutor G71 roughing article):
  `https://gcodetutor.com/cnc-machine-training/g75-groove-cycle.html`
  — States both forms explicitly: two-line `G75 R(1)` / `G75 X Z P Q R(2) F`, with R(1) = "Retract
  Amount" (per-pass X withdrawal) and P = "Peck depth in X-axis (**microns**)", Q = "Stepover
  distance in Z-axis (microns)", R(2) = optional relief at cut end; one-line `G75 X Z I K D F`
  with I = "Depth per peck (e.g., 1000 = 1mm removal)" and K = "Stepover in Z-axis". This is the
  only source that states the µm unit explicitly, and it matches the brief's P/Q-in-µm assumption
  and the I/K-in-mm one-line assumption (I given here as a plain mm-scale integer, "1000 = 1mm").

None of the reachable sources contradict the brief's P/Q assignment (G74: P=Δi X-step, Q=Δk
Z-peck; G75: P=Δi X-peck, Q=Δk Z-step), the µm units for P/Q, or the per-peck partial-retract
