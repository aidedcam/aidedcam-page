Fanuc two-line form:
    G76 P(m)(r)(a) Q(Δdmin) R(d)
    G76 X(U) Z(W) R(i) P(k) Q(Δd) F(L)

- m: finishing passes (2 digits); r: chamfer amount in 0.1·L units (2 digits); a: tool angle
  (80, 60, 55, 30, 29, 0).
- Δdmin: minimum depth of cut (µm, radius); d: finishing allowance (mm).
- X: thread root diameter; Z: thread end; i: taper (radius difference); k: thread height (µm, radius);
  Δd: first-pass depth (µm, radius); L: lead.

Depth of rough pass n: max(Δd·√n, previous + Δdmin), capped at k − d; then m finishing passes at k.
Pass X (radius) = crest − depth, where crest = root + k (external thread).
Single-flank infeed: on the control the start Z of each pass shifts by depth·tan(a/2). **Direction
unverified — no reachable source states the sign, so the viewer does not draw the shift (radial
infeed; a test asserts every pass starts at A's Z).**
Motion per pass as drawn: rapid A → (pass X, A's Z) · thread to Z end (chamfer pull-out when r > 0) ·
rapid X out to A.x · rapid Z back to A.z.

Haas one-line form (unverified — corroborated only via a same-letter Fanuc one-line article, see
below): G76 X Z K(height) D(first depth) A(angle) F(lead) [I(taper)].
v1 reads K and D as mm, uses min depth 0, finishing allowance 0 and one finishing pass.

Hand-worked example (becomes the test): from (r12.5, z5), G76 P020060 Q100 R0.05 /
G76 X17.4 Z-20 P1300 Q400 F2.
- Depths: 0.4, 0.565685, 0.692820, 0.8, 0.9, 1.0, 1.1, 1.2, 1.25, then 1.3, 1.3 (11 passes).
- Thread X (radius, crest 10): 9.6, 9.434315, 9.307180, 9.2, 9.1, 9.0, 8.9, 8.8, 8.75, 8.7, 8.7.
- 4 moves per pass = 44 segments.

## Sources checked

- helmancnc, "Fanuc G76 Threading Cycle" (secondary, tutorial site; reached from the helmancnc
  G-code list): `https://www.helmancnc.com/cnc-fanuc-g76-threading-cycle/`
  — Gives the two-line form `G76 P010060 Q100 R0.05` / `G76 X30 Z-20 P1024 Q200 F2`. First-line
  P: "first two digits (01) = number of spring passes or spring cuts", "next two digits (00) =
  thread run out at 45 degree", "last two digits (60) = flank angle or infeed angle". First-line
  Q: "depth of normal cut (given in hundreds, i.e. the depth of cut will be 0.1)". First-line R:
  "depth of last or finish cut". Second-line P: "thread depth (as radius value)". Second-line Q:
  "depth of first cut". Second-line F: "thread pitch". Confirms the brief's m/a and Δdmin/d/k/Δd/L
  reading. The "thread run out at 45 degree" phrasing for the middle P digit is consistent with
  the brief's r-as-chamfer reading (r sets the length of a runout that is cut at a fixed 45°), but
  does not itself state the 0.1·lead scale factor, so that multiplier stays unverified.
- gcodetutor, "G76 Two-Line Threading Cycle" (secondary, tutorial site; reached from the
  gcodetutor G71 roughing article, which links sideways to G76):
  `https://gcodetutor.com/cnc-machine-training/g76-thread-cycle.html`
  — States the same two blocks (`G76 P(1)(2)(3), Q, R;` / `G76 X, Z, P, Q, F;`) and is explicit
  where helmancnc was vague: P(1) = "spring passes: the number of spring passes that the machine
  will take once the thread is cut to depth" (m), P(2) = "chamfer angle: defines the angle of
  runout chamfer at the end of the thread" (r), P(3) = "thread angle: the angle of the teeth of
  the thread (60° metric, 55° BSF)" (a); first-line Q = "minimum cut... so the machine does not
  start taking 0.001mm cuts" (Δdmin); first-line R = "finish allowance: the amount of material we
  leave on before the finishing pass(es)" (d); second-line P = "the depth of thread in microns"
  (k, confirms µm units); second-line Q = "depth of first cut" (Δd); second-line F = thread
  pitch/lead. This directly confirms every word assignment the brief and `g76.js` use for the
  two-line form, including the µm unit for the second-line P (height).
- helmancnc, "Fanuc G76 Threading Cycle One-Line Format" (secondary, tutorial site; linked from
  the main G76 article; documented as Fanuc 10/11/15T, not Haas):
  `https://www.helmancnc.com/fanuc-g76-threading-cycle-one-line-format/`
  — One-line form `G76 X Z I K D A F P` with I = "amount of taper", K = "single thread depth",
  D = "depth of the first pass", A = "thread angle", F = "thread lead", P = "infeed method"; units
  not stated. This uses the same letters (K = height, D = first depth, A = angle, F = lead,
  I = taper) as the brief's Haas one-line form, which is corroborating evidence for that letter
  assignment even though it is not the Haas page itself (Haas's G76 page returned HTTP 403, tried
  once, not retried) and does not confirm mm vs µm for K/D.
- helmancnc, "G76 Thread Cycle CNC Programming Example" and "External Thread Cutting with G76
  Threading Cycle" (secondary, tutorial sites; worked-program pages, OCR-garbled in places —
  e.g. `QI00` for `Q100`, `FI.5` for `F1.5`):
  `https://www.helmancnc.com/g76-thread-cycle-cnc-programming-example/`,
  `https://www.helmancnc.com/external-thread-cutting-with-g76-threading-cycle-on-fanuc-21i-18i-16i-cnc/`
