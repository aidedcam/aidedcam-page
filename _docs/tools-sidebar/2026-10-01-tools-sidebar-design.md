# Free-tools sidebar: design

Date: 2026-10-01. Requested by Aris, with the decisions delegated ("go ahead on your own decisions"). This document is
the binding reference for the build.

## 1. Purpose

The top-nav link "ΔΩΡΕΑΝ ΕΡΓΑΛΕΙΑ" does not make the free tools visible. A slim strip on the left edge of every page
shows one icon per tool. Hovering (or focusing) an icon expands it into a card with the tool's name and one line about
it. A wider box at the bottom links to all free tools. The free tools are lead magnets, so the aim is more visits to
them from every page.

## 2. Decisions

| Question | Decision |
|---|---|
| Which pages | Every page: index, what-you-gain, calculator, free-tools, the six tool pages, legal, privacy |
| Tools listed, in order | Lathe G-code viewer, Milling G-code viewer, Laser DXF check, DWG quantities, Coverage pre-check, DXF floor plans from IFC (6) |
| Desktop (≥ 1200 px wide **and** a hover-capable fine pointer) | Fixed strip at the left edge, vertically centred: one 44 px square icon button per tool, plus the bottom box "Όλα τα δωρεάν εργαλεία →" |
| Hover / keyboard focus | The hovered or focused item expands to the right into a card: the tool's name (bold) and one line of description. Pure CSS, no layout shift for the page |
| Narrow screens and touch (below 1200 px, or no hover) | The strip is replaced by one floating button at the bottom-left, "Εργαλεία", with a wrench icon. A tap opens a compact panel listing the six tools (icon + name + line) and the "all tools" link. Esc, a tap outside, or the button closes it |
| Current page | The current tool's icon is marked as current (`aria-current="page"`); on free-tools.html the bottom box is marked |
| Languages | GR (default), EN, IT. The strings live in the sidebar script. It follows the page's language by watching `<html lang>`, because pages announce changes with different events. Italian uses formal voi and the typographic ’ |
| Implementation | One shared script, `js/sidebar.js`, injects the markup; one shared stylesheet, `css/sidebar.css`. Each page adds one `<link>` and one `<script defer>`, nothing else. No edit to `css/editorial.css` or `css/tools.css`. All inline SVG icons; no external requests |
| GA | `freetools_sidebar_click { tool, layout: strip \| panel }`, only through `window.gtag` when it exists (which is after consent). No names or figures |
| Print, reduced motion, consent banner | Hidden in print. No animation under `prefers-reduced-motion`. It must not cover the consent banner or its buttons. The floating button sits above the page but below the consent banner |
| Accessibility | A `<nav aria-label>`; every item is a real link with a visible focus ring and a text name; the card text is the link's accessible name; the floating button has `aria-expanded` and `aria-controls` |
| Overlap | On desktop the strip sits in the page's side gutter. At 1200, 1280 and 1440 px it must not cover any page content, text or control (checked by screenshots on every page); if a page has no gutter at a width, that width uses the floating button instead |

## 3. Also in this change

The live coverage pre-check's downloadable layer template (`js/coverage/examples/layer-template.dxf`, written by
`_tests/coverage/make-examples.mjs` through `_tests/coverage/dxf-writer.mjs`) names its text font `txt`, which has
no Greek glyphs in AutoCAD, ZWCAD or BricsCAD. It changes to `arial.ttf`, as in the IFC plans tool. The example
drawings are regenerated by the generator and `--check` must print `same` for all three.

## 4. Testing

- **Node:**
  - every page includes the stylesheet and the script with the same `?v=`;
  - the six tools and their URLs match free-tools.html;
  - strings exist in el, en and it, with no ASCII apostrophe in the Italian;
  - the existing suites stay green.
- **Browser check** (headless Chrome, same runner pattern as the other tools):
  - at 1440 px: the strip shows six items plus the all-tools box, a hover expands an item to its card, the current page is marked, and switching language changes the cards;
  - at 375 px: no strip, the floating button opens and closes the panel, and there is no horizontal page scroll;
  - no console errors and no external requests;
  - full-page screenshots of every page at 1280 px and 375 px, looked at by eye.
- **Other tools:** their existing browser checks still pass (DWG quantities 25, coverage 52, IFC plans 40).
